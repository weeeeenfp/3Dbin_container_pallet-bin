# 3D 棧板裝箱最佳化

針對物流出貨情境的 **3D 裝箱（3D Bin Packing）** 實作：讀取出貨清單，計算多尺寸紙箱該怎麼堆上棧板，並輸出可旋轉檢視的 3D 裝箱圖。

目標是減少所使用的棧板數量，同時滿足實務上的高度與載重限制。

## 問題設定

| 參數 | 值 | 說明 |
| --- | --- | --- |
| 棧板尺寸 | 1200 × 1000 mm | 歐規棧板 |
| 堆疊上限高 | 1650 mm | 含棧板本身總高 |
| 單棧板載重 | 1500 kg | 超過即開新棧板 |
| 允許擺放方向 | 6 種 | 長寬高三軸的全排列 |

## 演算法

採**啟發式（heuristic）**策略，分三個決策層：

1. **排序**：貨物依重量**由重到輕**處理，讓重物落在底層，符合實際堆疊安全要求。
2. **選棧板**：依序嘗試既有棧板，載重超限則跳過；全部放不下才開新棧板（First-Fit）。
3. **定位**：對每箱貨物試 6 種旋轉，檢查底面是否超出棧板邊界，再以 **Bottom-Left** 概念向下沉到最低可行高度 —— 掃描已放置貨物，取所有水平投影重疊者的頂面最大值作為落點 `z`，若 `z + 高度` 未超過上限即放置。

## 專案結構

```
main.py         # 流程入口：讀 Excel → 裝箱 → 輸出報表
packer.py       # 裝箱主邏輯（排序、選棧板、定位）
bin.py          # 棧板：承載貨物、累計重量、計算當前高度
item.py         # 貨物：尺寸、重量、座標、旋轉
point.py        # 三維座標
config.py       # 棧板規格與旋轉組合（集中管理參數）
visualizer.py   # Plotly 3D 視覺化，依尺寸上色並產生圖例
data/           # Excel 測資（長、寬、高、重量、數量）
```

## 執行方式

```bash
pip install openpyxl plotly
python main.py
```

測資放在 `data/`，格式為每列一種箱型：`長 / 寬 / 高 / 重量 / 數量`（單位 cm、kg）。
執行後會在同目錄產生 HTML 檔，用瀏覽器打開即可拖曳旋轉檢視每個棧板的堆疊結果，相同尺寸的箱子會以同色標示並列在圖例中。

主控台會輸出使用棧板數、各棧板的箱數／堆疊高度／總重與執行時間。

## 已知限制

這版是會跑的**基準版本**，刻意保持簡單以便驗證流程，目前的取捨如下：

- 水平定位僅取單一基準點，尚未實作完整的 extreme point / maximal space 搜尋，因此同層的平面利用率還有明顯進步空間。
- 未納入貨物耐壓強度、同客戶貨物集中擺放、出貨順序（後送先上）等實務約束。
- 未支援貨櫃層級的裝櫃（棧板 → 貨櫃），該部分在另一個三階段版本中處理。
- `Packer.unfitted` 目前僅宣告未實際記錄，裝不下的貨物尚未回報，待修。

後續方向是把定位策略換成 extreme-point based 搜尋，並以相同測資比較棧板使用數的差異。
